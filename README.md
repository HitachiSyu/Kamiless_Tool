# カミレス JSON ビジュアルエディタ

カミレス（Kamires）からエクスポートした帳票 JSON を、**ローカル・オフラインで可視化編集**するツール。背景画像の上に入力欄（form_part）を重ねて表示し、複数選択・ドラッグ移動・一括拡縮・コピー＆ペースト・番号の振り直し・背景画像の削除（容量削減）などを行い、**そのままカミレスに再インポートできる JSON** を書き出す。

公式のオンライン編集画面に無い「複数選択・まとめてドラッグ・Delete・コピペ・整列」を補うことが目的。

> **形態**：依存ライブラリ無しの単一 HTML ファイル。インストール不要・**完全オフライン**。最新版 **`Kamiless_Tool.html`** をブラウザでダブルクリックするだけで動く。読み込んだ JSON はすべてローカルのブラウザ内で処理され、外部へ送信されない。（PDF 取り込み用に PDF.js を HTML 内へインライン同梱しているため最新版は約 1.5MB。通信は一切発生しない。）

---

## 起動方法（ローカル・完全オフライン）

1. リポジトリ一式を取得（`git clone`、または GitHub の「Code」→「Download ZIP」）。
2. **`Kamiless_Tool.html`** をブラウザ（Chrome / Edge / Firefox の新しめの版）で**ダブルクリック**して開く。サーバー起動・インストール・ログイン不要。
   - 起動時に免責同意ダイアログを表示。「承知しました」で利用開始。

> JSON の読み込み・編集・書き出しは**すべてローカルのブラウザ内**で行われ、ファイルが外部へ送信されることはない。

## 使い方

1. 上記の方法でツールを開く。
2. 上部黒バーの **「JSON読込」** で、カミレスからエクスポートした JSON を読み込む。
3. 各ページの背景画像と、その上の入力欄（赤枠）が表示される。
4. 編集する（下表）。
5. **「JSON書出」** で `<元の名前>_修正済.json` をダウンロード → カミレスにインポート。

### 画面構成
- **左**：上段 = ページ一覧（**各ページの名前を表示・✎ で改名・🗑 で削除・ドラッグで並べ替え・「＋ページ」で空白ページ追加**、固定表示・折りたたみ可）／下段 = 構造ツリー（**セクション ▸ 対象項目 ▸ 入力欄** の 3 階層、当該ページ分のみ。見出しは固定＝スクロールしても残り、一括展開／折りたたみ切替あり）。
- **中央**：背景画像＋入力欄のキャンバス。
- **右**：3 タブ（**セクション／対象項目／入力欄**）。左ツリーで選んだ階層に応じて自動で切り替わり、その属性を編集できる。
- **左右のパネル幅は境界のバーをドラッグして調整可能**（長い名前が省略表示で読めないとき用。ダブルクリックで既定幅に戻る）。

| 操作 | やり方 |

| 入力欄を選択 | キャンバスでクリック／ツリーでクリック |
| 複数選択 | キャンバスで Ctrl/Shift＋クリック・空白からドラッグで矩形選択／**Ctrl+A で当該ページの全枠を選択**（画像外の枠も選べる）／左ツリーで Ctrl＋クリックで複数ノード選択（選択した全ノードがキャンバスでハイライト） |
| まとめて移動 | 選択した枠をドラッグ（近接する他の枠の辺・中心に**スナップ**、橙の補助線表示） |
| まとめて拡縮 | 選択範囲の四隅ハンドルをドラッグ |
| 元に戻す／やり直し | Ctrl+Z ／ Ctrl+Y（Ctrl+Shift+Z） |
| コピー／貼り付け | Ctrl+C → Ctrl+V（落とし先に応じて配置）／Ctrl+Shift+V（強制的に独立新規）。入力欄・**項目とも複数選択したまとめてコピー可**（項目は Ctrl＋クリックで複数選択） |
| 削除 | Delete キー、または「削除」ボタン |
| 番号の変更 | 右パネルで「セクション番号／項目番号／入力欄番号」を入力 → 同じ親の中で**挿入式に振り直し**（11→2 にすると元の 2〜10 が 3〜11 に） |
| 番号をドラッグで変更 | 左ツリーのノードをドラッグして並べ替え（ドラッグ中はホイール／端で自動スクロール） |
| 別の親へ移動 | 左ツリーで入力欄を別の対象項目・セクションへ、対象項目を別セクションへドラッグ（緑ハイライト=中に入る） |
| 番号一括整列 | 「番号一括整列」ボタン：位置（上→下・左→右）順に 3 階層すべて振り直し |
| 新規追加（選択に応じた落とし先） | 「＋入力欄」＝項目選択中はその項目へ／セクションのみ選択はそこに新規項目を作って配下へ／未選択はセクションごと新規。「＋項目」＝セクション選択中はそこへ／未選択は新規セクションへ。「＋セクション」＝常に新規（有効な 18 桁 ID を自動採番） |
| 背景画像を削除 | 上部「背景画像を削除」→ `image=null`（容量最小・インポートOK）。配置確定後に実行し、カミレス環境で画像を再添付する運用 |
| 背景を占位画像に | 「→占位1x1」：寸法を保ったまま 70 バイトの 1×1 画像に置換 |
| 背景画像をアップロード/差し替え | 「画像UP」：画像ファイルを選んで背景に設定（寸法も自動更新。画像未設定ページにも追加可） |
| 背景の罫線にスナップ | 「罫線スナップ」ON でドラッグ時に背景の罫線へ吸着（「検出%」で感度調整） |
| 色から自動で枠生成 | 「自動枠生成」：指定色（調色盤／「スポイト」で背景から採色）＋容差で該当色のセルを一括生成。「範囲指定」で対象範囲をドラッグ限定（未指定は全体） |
| 削除（階層対応） | 入力欄選択時=その枠／対象項目選択時=項目＋配下入力欄／セクション選択時=セクション一式（項目・セクション削除は確認あり） |
| 複数まとめて削除 | 左ツリーで Ctrl＋クリックして項目／セクションを複数選択 → Delete で**まとめて削除**（数量を確認のうえ、編号も自動で振り直し）。Ctrl+A→Delete で枠を一括削除 |
| PDF から背景を取り込み | 「画像/PDF」で PDF を選ぶ → ページ選択モーダルでサムネイルから 1 ページを選び、解像度（既定 150dpi）を指定して背景画像化（完全オフライン・PDF.js 同梱） |
| 別テンプレートからコピー | 「コピー元を開く」で別の帳票 JSON を開く → ツリーで**セクション丸ごと／項目だけ**をチェック（ページ横断可）→「選択をコピー」→ メイン側「貼付」で現在ページに追加（ID 再採番・座標維持。「背景に合わせ拡縮」で寸法差を自動補正） |
| ページ丸ごとを新規ページとして挿入 | 「コピー元を開く」で各ページ見出しの「新規ページとして挿入」にチェック →「選択をコピー」→「貼付」で、**背景画像ごと 1 ページを末尾に新規追加**（form_layout/画像/セクションの ID を全て再採番） |
| ページ名の表示・変更 | 左のページ一覧に各ページ名（`layout_title`）を表示。行末の ✎ で改名（`layout_title`/`name`/`form_template_name` を同時更新） |
| ページの並べ替え | 左のページ一覧で**ページ行をドラッグ**して順序変更（挿入式）。`layout_number` と各セクションの `form_layout_number` を自動で追随（内容がページから外れない） |
| 未使用要素を掃除 | 「未使用要素を掃除」：**未関連枠 → 枠が無い空項目 → 項目が無い空セクション**の順に級联削除（枠のサイズ・位置は条件にしない＝項目に属する枠は大きさ 0 でも残す）。確認あり・Undo 可 |
| 欄名→項目名 | 「欄名→項目名」：入力欄が**1 つだけ（1 対 1）**の項目について、その入力欄名（`part_name`）を項目名（`field_label`）へ一括コピー。**既存の項目名も上書き**（入力欄名が空のものは対象外）。Undo 可 |
| 背景画像を圧縮 | 「背景圧縮」→ オプション（最大幅で縮小／二値化＋しきい値／対象ページ）を選んで実行。枠座標も同倍率で自動スケール。取り消しは **「圧縮を戻す」**（原画像・座標をメモリから復元。Ctrl+Z 不可。再読込で無効）。退避データは `J` に入らず書き出しに残らない |
| ズーム | 上部「＋／－」ボタン、または中央キャンバス上で **Ctrl＋マウスホイール**（カーソル位置を中心に拡大縮小。Ctrl 無しのホイールは通常スクロール） |
| 座標・サイズを揃える | 入力欄を 2 つ以上選択して「**列揃え(X)／行揃え(Y)／列内幅揃え／行内高揃え**」。選択枠を自動で列/行にクラスタリングし、各列/行ごとに X・Y・幅・高さを最小値へ統一（行列マトリクスも 1 回で整列。1 列/1 行だけなら全部同値）。分割の「**整列許容**」px は可変（既定 15）。Undo 可 |
| パネル幅の調整 | 左右パネルの境界バーをドラッグして幅を変更（ダブルクリックで既定に戻す） |
| 空白ページを追加 | 左「ページ」欄の「＋ページ」：背景なし（`image=null`）の空白ページを末尾に追加（`layout_number` 自動採番・追加後そのページへ移動。背景は「画像/PDF」で設定） |
| ページを削除 | 左「ページ」欄の各行の 🗑：そのページ（`form_layout`）と配下セクション・入力欄を削除。後続ページの `layout_number` と各セクションの `form_layout_number` を自動で詰める。確認あり・最後の 1 ページは削除不可・Undo 可 |
| 構造の一括展開／折りたたみ | 左「構造」欄見出しの切替ボタン：全セクション・項目をまとめて展開⇄折りたたみ（全ページ分。ボタン表示は次の動作を示す） |
| 選択の解除 | 中央キャンバスの空白／**左ツリーの空白**をクリックで選択解除 |

## 公式オンライン編集との違い（改善点）

本ツールの主目的は、**カミレス公式のオンライン編集画面に無い「一括・効率編集」を補う**こと。公式は 1 個ずつしか扱えず、複数選択もコピペも元に戻すも無いため、入力欄の多い帳票では非常に手間がかかる。

| 機能 | 公式オンライン編集 | 本ツール |
|---|---|---|
| 複数選択 | ✕ なし | ✓ Ctrl/Shift＋クリック・矩形選択 |
| まとめて移動 | ✕ | ✓ ドラッグで一括移動 |
| まとめて拡縮 | ✕ | ✓ 選択範囲の四隅ハンドルで一括 |
| Delete 削除 | ✕（やりづらい） | ✓ Delete キー／ボタン |
| コピー＆ペースト | ✕ | ✓ Ctrl+C/V（落とし先連動・独立/共有の切替） |
| 元に戻す／やり直し | ✕ | ✓ Ctrl+Z／Ctrl+Y |
| 番号の挿入式振り直し | 手作業で 1 つずつ | ✓ 値を変えると同じ親の中で玉突き自動 |
| 番号の一括整列 | ✕ | ✓ 位置（上→下・左→右）順に 3 階層を自動採番 |
| ツリーでドラッグ並べ替え／所属変更 | ✕ | ✓ 別の項目・セクションへドラッグ |
| 整列スナップ（他の枠の辺・中心へ吸着） | ✕ | ✓ 橙の補助線付き |
| 背景画像の容量削減（4MB 制限対策） | △ 添付を手動で外す | ✓ ワンクリックで `image=null`（最小化・再添付運用） |
| 動作環境 | ブラウザ＋ログイン必須・オンライン | ✓ 単一 HTML・インストール/ログイン不要・**完全オフライン** |

> 要するに「公式で 1 個ずつやると地獄な作業（位置合わせ・整列・番号振り・大量配置）」を、まとめて・取り消し可能・オフラインで行えるのが本ツールの価値。

## 開発履歴

最初の MVP から、ユーザーの実利用フィードバックを 1 バージョン 1 フォルダで反復。各版は前版の全機能を含む。

### v1 — MVP
- JSON 読込／多ページプレビュー（背景＋SVG 枠）
- 単一・矩形・複数選択、ドラッグ移動、四隅ハンドルで一括拡縮
- ＋入力欄／＋項目／＋セクション（有効な 18 桁 Salesforce ID を自動採番）
- 属性編集、Delete 削除、ズーム、**保全書き出し**（未編集フィールドは原文のまま）
- → 「公式に無い複数選択・ドラッグ・Del がある」と高評価。以降を反復開発。

### v2 — 構造ツリー＋編集基盤
- 左ツリーを **3 階層（セクション▸対象項目▸入力欄）** 化、当該ページのみ表示（bug 修正）
- 右 **3 タブ**：選択ノードに連動。未対応フィールドも**書き出し時に保全**
- **Undo/Redo**（Ctrl+Z/Y）。スナップショットから**画像を除外**して軽量化
- **コピー＆ペースト**（Ctrl+V／Ctrl+Shift+V）
- **項目番号・セクション番号**の設定＋挿入式の自動振り直し
- 左ツリーの**ドラッグ並べ替え**、**整列**ボタン、**整列スナップ**（補助線）
- 🐞 修正：ID 採番が `slice` で重複していた不具合 → 純増カウンタ方式に

### v3 — 入力欄番号（diff による確証後）
- ユーザーが「番号 4→1」前後の JSON を提供 → **diff** で確定：
  **入力欄番号 = `part_order`、親 = 対象項目**（同一項目内で 1 から、項目間は独立）。挿入式振り直し
- 入力欄番号の編集・ツリードラッグ並べ替え・一括整列に対応
- 🐞 修正：新規／貼付の `part_order` を「ページ全体の max+1」から「**対象項目内の max+1**」へ

### v4 — UX 強化
- ① 枠を選ぶと**左ツリーが自動スクロール**して該当行へ
- ② ページ一覧を**上部固定＋折りたたみ**、構造ツリーは独立スクロール
- ③ ツリーのドラッグを **HTML5 draggable から自作マウスドラッグへ**変更 → ドラッグ中も**ホイールでスクロール**＋**端で自動スクロール**（200 番目を 1 番目へ移動可能に）
- ④ 跨ページコピー不具合の修正、**別の親へドラッグして所属変更**、**選択先に応じた貼り付け**、**対象項目ごとコピー**
- ⑤ 背景画像サイズ表示＋削除ボタン

### v5 — 画像まわり修正（その1）
- 🐞 占位画像が `data:image/png;base64,...`（接頭辞付き）で、`:` が不正 base64 → **純 base64** に修正
- 「空にする」削除は `バージョンデータ` エラーになるため一旦撤去

### v6 — 画像削除を正しく
- ユーザーが「カミレス標準の削除後も導入できる JSON」を提供 → 確認：
  **カミレスの画像削除 = `image` フィールドを `null` にする**（data を空にするのではない）
- 「背景画像を削除」を **`image=null`** に修正（容量最小・インポートOK）。「→占位1x1」も併存

### v7 — 起動時の免責同意ダイアログ
- 起動時に免責事項（非公式サードパーティ製ツールである旨／100% ローカル動作・データ非送信／無保証・重要環境は事前バックアップ推奨）の同意ダイアログを表示。「承知しました」で閉じて利用開始
- ダイアログは独立した inline 要素で、「承知しました」で自身を取り除くだけ。ツール本体の動作には影響しない

### v8 — 画像アップロード／罫線スナップ／色からの自動枠生成
- **画像アップロード/差し替え**：画像ファイルを背景に設定（寸法自動更新・画像なしページにも追加）
- **罫線スナップ**：背景画像の罫線（黒い縦横線）を検出し、ドラッグ時に吸着（感度調整可）
- **色から自動枠生成**：指定色（調色盤／スポイト採色）＋容差で該当セルを入力欄として一括生成。青色固定だった検出を任意色へ一般化。「範囲指定」で対象範囲をドラッグ限定（未指定は全体）
- 🐞 **削除の修正**：選択中の階層（入力欄／対象項目／セクション）に応じて本体ごと削除（以前は配下の入力欄しか消えなかった）

### v9 — PDF からページ背景取り込み／空白 JSON での新規作成
- **PDF 背景取り込み**：「画像/PDF」で PDF を選ぶ → 全ページのサムネイル一覧から 1 ページを選択し、解像度（既定 150dpi）でラスタ化して背景に設定。**PDF.js を HTML へインライン同梱**（外部通信なし・`file://` でも Blob ワーカーで動作）
- 🐞 **空白 JSON の新規作成不可を修正**：セクションが 1 つも無い JSON では `＋セクション/項目/入力欄` が無反応で落ちていた（テンプレ元が null）。カミレス実ファイルから採取した**完全な既定テンプレ**を内蔵してフォールバックし、配列キー欠落も補完

### v10 — ツリーのドラッグ修正／複数ドラッグ
- 🐞 **項目を別セクションへドラッグできない不具合を修正**：落とし先が「入力欄行」だと項目のドロップが不正扱いになり、入力欄だけ移動して項目が残っていた → どの行（セクション/項目/入力欄）に落としても所属を解決するよう統一
- **複数ドラッグ**：左ツリーで Ctrl＋クリックして複数ノードを選択 → まとめてドラッグ移動

### v11 — 別テンプレートからのコピー（部分コピー対応）
- **コピー元を開く**：別の帳票 JSON を参照用に開き（本体は無変更）、ツリーで**セクション丸ごと／項目だけ**をチェックして選択（ページ横断可）
- **貼付**：選択をメイン側の現在ページに追加。ID を全て再採番、座標は維持。項目だけのコピーは選択中セクション（無ければ新規「コピーした項目」）へ。「背景に合わせ拡縮」で背景寸法差を自動補正
- 🐞 ツールバー要素欠落でツール全体が初期化失敗していた不具合を修正

### v12 — Ctrl+A 全選択／複数選択の操作完成
- **Ctrl+A**：当該ページの全入力欄を一括選択（画像が小さく**画像外にはみ出した枠**もまとめて選べる）
- **複数選択のまとめて削除**：左ツリーで複数選択した項目／セクションを Delete で一括削除（数量確認・編号自動振り直し）

## 原理（どうやって作ったか）

**カミレスのソースコードは一切見ていない。** すべて**エクスポートされた JSON を観察・逆推論**して仕様を割り出した。

- **構造の把握**：実ファイルを多数読み、`form_layouts`（ページ）・`target_field_sections`（項目定義）・`form_parts`（入力欄）の関係を推定。
- **未知フィールドの確定は diff で**：仕様が不明な値（特に「入力欄番号」）は、**公式画面で 1 箇所だけ変更 → 再エクスポート → 変更前後の JSON を 1 フィールドずつ比較**し、どの値がどう動くかで意味を断定した（例：番号 4→1 にしたら `part_order` が 4→1、他が玉突きで +1 → 「入力欄番号 = part_order、挿入式」と確定）。
- **画像削除の挙動**も、公式で削除した実ファイルを観察して `image=null` だと判明（推測で `data=""` にしてエラーを出した後、実物で訂正）。

### 逆推論で判明した主要仕様
- 座標系：`form_part` の `x,y,width,height` は**背景画像のピクセル左上基準**（そのまま表示＝WYSIWYG）。
- 階層と番号（いずれも**挿入式**・親の中で 1 から連番）：
  | 概念 | JSON | 値 | 親（採番範囲） |
  |---|---|---|---|
  | セクション | `target_field_sections[]` | `section_number` | ページ（`form_layout_number`） |
  | 対象項目 | `section.target_fields[]` | `field_number` | セクション |
  | 入力欄 | `form_layouts[p].form_parts[]` | `part_order` | **対象項目**（`fp.target_field` で関連。物理包含ではない） |
- 1 つの対象項目に**複数の入力欄**が紐づくことがある（チェックボックス群等）。
- **ID は 18 桁 Salesforce ID**（15 桁ベース＋3 桁チェックサム）。不正だと `malformed id ...` で落ちる。新規要素は必ず有効 ID を採番する。プレフィックス：入力欄 `a0G`／対象項目 `a0V`／セクション `a0T`／**ページ(form_layout) `a0E`／背景画像 `068`**。
- **ページ名** = `layout_title`（= `name` = `form_template_name`。3 者同値）。ページ(form_layout)自身は `layout_number`、セクションは `form_layout_number` でページに紐づく。
- **セクションの `form_layout_number` は、その枠が物理的に載っているページと必ずしも一致しない**（1 つのセクションの枠が複数ページに跨がり得る）。表示はあくまで枠の物理ページ（`form_layouts[p].form_parts`）で判断する。
- **`image.data` は接頭辞なしの純 base64**。`image` を消すときは **`image=null`**（`data=""` は `REQUIRED_FIELD_MISSING: バージョンデータ` で落ちる）。
- **保全が最重要**：UI に出していないフィールドも含め、未編集の値は原文のまま書き出す（編集はメモリ上の元オブジェクトの参照を直接書き換え、出力は元オブジェクトをそのまま `JSON.stringify`）。

## 技術スタック

- **単一 HTML ファイル**：依存ライブラリ・ビルド・サーバー無し。完全オフライン、ダブルクリックで起動。
- **HTML + CSS（CSS Grid レイアウト）+ 素の JavaScript（ES6+）**。フレームワーク不使用。
- **SVG** でキャンバスの枠を描画：`viewBox` を背景画像のピクセル寸法に合わせ、`getScreenCTM().inverse()` で画面座標↔ドキュメント座標を変換（拡大率に依らず正確）。
- **ブラウザ File API** で入出力（`<input type=file>` 読込／Blob ダウンロード）。バックエンド無し。
- **データモデル＝パースした JSON オブジェクトそのもの**を直接編集（保全往復のため）。
- **Undo/Redo** は軽量スナップショット（`form_parts` と `target_field_sections` のみを文字列化、巨大な画像 base64 は除外）。
- 検証は **Node によるヘッドレス確認**（番号振り直し・ID 採番・所属変更・往復保全などの純ロジックをミニデータで検査）。GUI 操作の手触りは人手で確認。
- 将来的に **Tauri** で `.exe` 化可能（WebView に同 HTML を載せるだけ。Rust/Node は導入済み）。
